# Meowza assets

The v1.1 runtime loads `backgrounds/cat-tree.webp`, `cats/nimbus.webp`, and `cats/moka.webp`. The original PNG collection remains for history but is not loaded. UI, platform interaction, cloud masks and relation symbols are drawn by Phaser.

The new illustrations were generated specifically for Meowza using the built-in image-generation tool. See `docs/assets.md` for briefs and delivery locations. Nunito is bundled from `@fontsource/nunito` under its SIL Open Font License.
